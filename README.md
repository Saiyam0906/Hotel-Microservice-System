# Hotel Booking Microservices System

A Spring Boot based Microservices Architecture for Hotel Booking System.

## Architecture

This system consists of the following microservices:

- API Gateway
- Service Registry (Eureka Server)
- Config Server
- User Service
- Hotel Service
- Rating Service

## Tech Stack

- Java
- Spring Boot
- Spring Cloud
- Eureka Service Discovery
- OpenFeign
- REST API
- Maven
- MySQL

## Features

- Microservices-based architecture
- Service discovery using Eureka
- Centralized configuration using Config Server
- Inter-service communication using Feign Client
- RESTful APIs for Hotel, User and Rating Services

## Future Enhancements

-Using Ressilance4j for Fault Tolerance
-Using okta for security at both Api gateway and to the internal services
-integration of spring ai for hotel recommendation
-Deployment using AWS(S3,RDS,EC2)
